Welcome to Forge OS

Forge OS is a documentation-first PDLC automation framework. AI agents guide your team through 11 stages — from raw idea to production-ready release and marketing.

This setup takes about 3 minutes. You'll configure GitHub authentication and connect your organization's shared knowledge repository.

What you'll need
1
A GitHub account (personal or organization member)
2
If you're the first person setting this up: admin access to your GitHub organization
3
If you're a team member: your organization's name on GitHub (e.g. acme-corp)

Are you setting this up for the first time?

This determines whether you register a new GitHub OAuth App or connect to an existing organization setup.

Register a GitHub OAuth App

Forge OS uses GitHub for authentication. You register one OAuth App per organization — team members never need to do this.
Step-by-step
1
Click Open GitHub below — it opens the registration page
2
Fill in the form:
· Application name → Forge OS
· Homepage URL → any URL (e.g. http://localhost)
· Callback URL → http://localhost
· Enable Device Flow → ✅ checked
3
Click Register application
4
Copy the Client ID shown at the top of the next page (starts with Ov23li)
From the GitHub OAuth App page — looks like Ov23liXXXXXXXXXXXXXX ✓ Client ID looks valid

Connect to your organization

Enter your GitHub organization name. Forge OS will pull the configuration that your admin set up.

The part after github.com/ — e.g. acme-corp
This organization's repository is private. Ask your admin for the OAuth App Client ID (starts with Ov23li).

Connect your GitHub organization

Forge OS syncs shared knowledge and configuration from a private repository in your GitHub org.

The part after github.com/ — e.g. acme-corp
The repo in your org that holds shared context — defaults to forge-knowledge
