Capabilities

Everything from idea to shipped

One tool drives the entire product delivery lifecycle — no stitching together a dozen SaaS tools.

AI-generated docs
Write ideas in Markdown; Forge generates requirements, design specs, and architecture docs through 11 structured pipeline stages.
Review & gate system
Every generated document must be reviewed and approved before the pipeline advances. File-level critique regeneration and gate sign-off included.
AI cost controls
Route each generate stage to a fast or strong model. Batch generation sends a stage's shared context once instead of per file, with a projected-token preview before you spend.
New
Phase timeline
Track delivery phases (MVP, v1.0, beta) parsed from roadmap docs, with in-progress status at a glance.
Team collaboration
Admins publish an org config once. Every member connects by entering the org name. Roles: admin, member, viewer. Shared knowledge base across all projects.
Knowledge base
Export reviewed docs to a separate KB repo as a PR. AI distills global patterns, decisions, and learnings across all your projects over time.
Issue tracker
Lightweight built-in tracker linked directly to your pipeline stages. Log bugs and tasks without leaving the dashboard — no JIRA required.
Multi-project
Manage unlimited independent projects from one dashboard. Each has its own pipeline and review state.
Cross-platform desktop
Native app for macOS (Apple Silicon + Intel), Windows 10+, and Linux. Silent auto-updates. GitHub Device Flow auth — no plain-text credentials stored.

Quick Start

Running in under 2 minutes

Install the desktop app or run the CLI directly. No account. No API keys required to start.

  1. 1
    Download & open
    Get the installer for your platform from the Downloads section below. Run it — the app starts on first launch.
  2. 2
    Create a project
    Click + New Project in the Projects view. Give it a name and Forge initializes the workspace.
  3. 3
    Add your idea
    Paste product notes in the Input tab — as rough as you like. One Markdown file is enough to start the pipeline.
  4. 4
    Run the pipeline
    Click Generate All. Forge runs all 11 stages and produces a complete product spec from your raw input.
  5. 5
    Review & approve
    Review each generated document, regenerate any section with a critique, and approve the gates to lock in your product spec.
# Install Forge CLI
$ ./forge init
Initialized .forge/ in current directory
 
# Generate all pipeline stages
$ ./forge pipeline
✓ context · requirements · design …
✓ architecture · engineering · qa
 
# Start the dashboard
$ ./forge dashboard 8080
Dashboard ready → http://localhost:8080
 
# Upgrade after rebuild
$ ./forge upgrade
Runtime scripts updated, data preserved
Team setup

One install, one org, whole team connected

Admin registers once. Every team member connects in under a minute with their GitHub credentials.

Admin

Set up for your organization

  1. 1 Download and open Forge OS
  2. 2 Choose "I'm the admin" in the setup wizard
  3. 3 Register a GitHub OAuth App (step-by-step guide built in)
  4. 4 Connect your GitHub organization
  5. 5 Forge publishes forge.config.json to your org repo automatically
Member

Join your team

  1. 1 Download and open Forge OS
  2. 2 Choose "I'm a team member"
  3. 3 Enter your GitHub organization name
  4. 4 Forge auto-connects and pulls the org configuration
  5. 5 Authenticate with GitHub — you're ready

Private org repos are supported — your admin provides a Client ID during setup.

Supported platforms

macOS · Windows · Linux

All builds are published automatically on every version bump. Download links below always reflect the latest release.

macOS
macOS 12 Monterey or later
Apple Silicon (.pkg) Intel x64 (.pkg)
The .pkg installer auto-clears the quarantine attribute — no Terminal steps needed for most users.

If Gatekeeper blocks the app: until notarized, macOS may show "Forge OS" is damaged. Run once: xattr -cr "/Applications/Forge OS.app" open "/Applications/Forge OS.app" Or go to System Settings → Privacy & Security → Open Anyway.
Windows
Windows 10 or later (x64)
x64 NSIS Installer (.exe)
Run the installer. Windows SmartScreen may warn on unsigned builds — click More info → Run anyway.

Auto-updates are delivered silently once the app is running.
Linux
AppImage
Ubuntu 20.04+ / Debian / Fedora (x64)
x64 AppImage (.AppImage)
Make the file executable, then run it: chmod +x forge-os-*.AppImage ./forge-os-*.AppImage For secure credential storage: sudo apt install libsecret-1-0
