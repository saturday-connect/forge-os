Capabilities

Everything from idea to shipped

One tool drives the entire product delivery lifecycle.

AI-generated docs
Write ideas in Markdown; Forge generates requirements, design specs, and architecture docs through 11 structured stages.
Review & gate system
Every generated document must be reviewed and approved before the pipeline advances to the next stage.
Build generation
Generates CI/CD pipelines, Dockerfiles, and env configs directly from your architecture docs.
Multi-project
Run Forge at the root of your repo and orchestrate multiple independent products from one dashboard.
Team collaboration
Admins publish an org config once; every team member connects by entering the org name. Roles: admin, member, viewer.
Silent auto-updates
Ships as a self-updating desktop app. Background downloads, release notes in the restart prompt, retry on transient errors.
Deploy & secrets
Tracks required secrets, pushes them to GitHub via API, and reports environment readiness before you ship.
Cross-platform
Native desktop app for macOS (Apple Silicon + Intel), Windows 10+, and Linux (AppImage). GitHub Device Flow auth — no plain-text credentials.

Team setup

One install, one org, whole team connected

Admin registers once. Every team member connects in under a minute.

Admin

Set up for your organization

  1. 1 Download and open Forge OS
  2. 2 Choose "I'm the admin" in the setup wizard
  3. 3 Register a GitHub OAuth App (step-by-step guide built in)
  4. 4 Connect your GitHub organization
  5. 5 Forge publishes forge.config.json to your org repo automatically
Member

Join your team

  1. 1 Download and open Forge OS
  2. 2 Choose "I'm a team member"
  3. 3 Enter your GitHub organization name
  4. 4 Forge auto-connects and pulls the org configuration
  5. 5 Authenticate with GitHub — you're ready

Private org repos are supported — your admin provides a Client ID during setup.

Supported platforms

macOS · Windows · Linux

macOS
macOS 12 Monterey or later
Apple Silicon (.pkg) Intel x64 (.pkg)
Download and run the installer. The installer automatically configures the app to run on your system.

Current beta Gatekeeper fix: until the app is Apple notarized, macOS may show "Forge OS" is damaged and can't be opened. After installing, run this once in Terminal: xattr -cr "/Applications/Forge OS.app" open "/Applications/Forge OS.app" Or open System Settings → Privacy & Security, scroll to Security, and click Open Anyway for Forge OS if macOS shows that option.
Windows
Windows 10 or later (x64)
x64 NSIS Installer (.exe)
Run the installer. Windows SmartScreen may warn — click "More info → Run anyway" for unsigned builds.
Linux
New
Ubuntu 20.04+ / Debian / Fedora (x64)
x64 AppImage (.AppImage)
Make the file executable, then run it: chmod +x forge-os-*.AppImage ./forge-os-*.AppImage Secure credential storage requires libsecret:
sudo apt install libsecret-1-0
